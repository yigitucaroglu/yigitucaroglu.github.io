Hakkımda

Kurumsal web uygulamalarının backend tarafını C# ve .NET ile geliştiriyorum. Yeni özellik geliştirmeden harici servis entegrasyonlarına, canlı ortam bakımından yayın süreçlerine kadar yazılımın farklı aşamalarında sorumluluk aldım.

Stajla başlayan kariyerimde uzak sunucu yönetimi, enerji tahmini, bayi ve operasyon yönetimi ve şirket içi iletişim gibi farklı alanlarda uygulamalar geliştirdim. ASP.NET Core, Entity Framework Core ve SQL Server ile REST API'ler geliştirdim; SignalR ile gerçek zamanlı iletişim, ödeme ve SMS entegrasyonları, yetkilendirme ve arka plan işlemleri üzerinde çalıştım. Canlı ortam sorunlarını log ve veritabanı analiziyle inceleyip kalıcı çözümler uyguladım.

Yeni bir özellik geliştirmek kadar çalışan bir sistemi sağlıklı tutmayı da önemsiyorum. Backend odaklı yeni fırsatlara açığım.

Kurumsal Talep ve Onay Yönetim Sistemi

Kişisel proje · GitHub'da herkese açık

Masraf, ekipman, izin ve diğer taleplerin yönetici onayından, yapılandırılabilir eşik tutarını aşanlarda ikinci seviye onaydan geçtiği rol bazlı (Çalışan, Yönetici, Admin) şirket içi talep yönetim sistemi.

  • Clean Architecture (Domain, Application, Infrastructure, Api, Web) ve MediatR ile CQRS
  • 15 dakikalık JWT access token; her kullanımda yenilenen ve veritabanında yalnızca SHA-256 özeti saklanan refresh token
  • Token'ları tarayıcıda tutmayan Razor BFF katmanı ve HttpOnly cookie
  • API tarafında her istekte rol, kayıt sahipliği ve departman yöneticisi denetimi
  • Rate limiting, RowVersion ile optimistic concurrency, soft delete
  • Hassas değerleri maskeleyen transactional audit logging
  • 260 unit ve 235 integration test; integration testler gerçek SQL Server üzerinde çalışır
  • .NET 8
  • ASP.NET Core Web API
  • EF Core
  • SQL Server
  • MediatR
  • xUnit
  • Swagger
